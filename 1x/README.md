NOTE: this project requires .NET 3.0 and Visual Studio 2008 and above.

You can also use Expression Blend or Blend for Visual Studio 2013 and above
if you want for more design, effects, etc.

To compile MuzixBokx, make sure that beside debug button is set to "Debug".
Then, press Crtl+Shift+B to build or Build -> Build Solution.
Next, right click on the project and select "Open Folder in Explorer".
Afterwards, double-click on bin and find Debug
Finally, open MuzicBokx.exe file and enjoy.

NOTE: you can see I have some 1.0, 1.5 (beta) don't have their own source code unlike the current 1.5
version, download dotPeek and decompile 1.0 or beta version (you can choose it depending on your choice
but I've recommended to decompile version 1.0 thus it has its smallest features that is great for beginners).
